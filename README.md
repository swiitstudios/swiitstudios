## 📁 Repository Structure
This repository contains the visual layout files simulating the SweetOS environment:
* `/components` - Reusable UI components and application layout blocks.
* `/assets/icons` - Vector graphics and core interface system icons.
* `/css` - Global layout styling rules and application shell themes.
* `/js` - Frontend simulation logic and dashboard script interactions.
* `index.html` - The central entry-level web view.
